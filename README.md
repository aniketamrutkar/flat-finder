# Flat Finder

Flat listings, rentals and registered sale and rent prices for Malad West and Goregaon West, Mumbai.

`index.html` is built on my laptop by `build_viewer.py` in the housing-transactions project. It is password-protected: the data is encrypted (AES-256, with a key derived from the passphrase by PBKDF2), and the page decrypts it in the browser.
